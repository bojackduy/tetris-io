All three files were downloaded over HTTPS on **2026-11-22**. The stored files are
**unchanged** from these URLs. The adapter decodes them once and scales their
playback peaks to leave room for overlapping effects; `comboTones.mp3` is sliced
in memory using the exact sprite parameters verified from Jstris's shipped
`replayer.js` (`RainforestSFXset`) and `game.js` (`loadSounds`): `cnt = 15`,
`duration = 1000 ms`, `spacing = 500 ms` (`startTime = i * 1500 ms`).

## Original replacements and fidelity gaps

`Start`, `Move`, `Rotate`, `Hold`, and `PerfectClear` are original short
synthesized effects generated by `src/adapters/audio.rs`, covered by this
repository's MIT license. In Jstris's `RainforestSFXset`, `move` and `hold` are
explicitly `null` (silent) and `harddrop` aliases `lock.mp3`. Combo tones use
the exact 15 Rainforest sprite segments (`c0` through `c14`); combos past 15
reuse `c14`.

Jstris also fetched these shared/default-pack resources during the browser
inspection:

- <https://s.jezevec10.com/res/se0/linefall.wav>
- <https://s.jezevec10.com/res/se0/success.ogg>
- <https://s.jezevec10.com/res/se0/ready.wav>
- <https://s.jezevec10.com/res/se0/go.wav>

The Rainforest credit does not establish a separate per-file license for this
mixed `se0` group. These files are **not bundled**, and no blanket CC BY claim is
made for them. Original replacements fill those roles. In particular, `Start`
is one short arpeggio, not Jstris's ready/go countdown.

This is therefore a **partial Rainforest adaptation**, not an exact sound-pack
replica. The runtime decides whether to emit start/rotation/movement cues and
must emit action cues only for successful actions. The inspected browser used
volume 60%, start enabled, and rotation disabled.

## Verification

Device-free decoder, cue bounds, mute, gain-clamp, and disabled-output tests:

```sh
cargo test --example audio_check
```

Brief real-device check (30% volume, approximately 1.3 seconds):

```sh
cargo run --example audio_check
```

The check reports whether a default output device opened. It cannot prove what
a listener heard; listening and end-to-end terminal gameplay remain separate
checks.
